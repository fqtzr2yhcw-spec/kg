## The short version

Built from the store's own Poshmark Sales Report (Apr 2026 window): 4 sales,
$103 gross, $82 net. Three of four items sat ~2 years before selling; the one
that was freshly listed, offered, and new-with-tags sold the same day. That one
insight — **freshness + offers + complete, keyword-rich listings** — is the whole
strategy, and it maps directly onto eBay and Etsy:

- **Poshmark:** share twice daily, Offer to Likers, relist stale items, list fresh.
- **eBay:** Offers to Watchers, fill every item specific, Promoted Listings + Sell Similar.
- **Etsy:** all 13 tags as phrases, front-loaded SEO titles, renew + Etsy Ads, free shipping.
- **Across all three:** cross-list one inventory, and delist fast when something sells.

See **[`GROWTH_PLAN.md`](./GROWTH_PLAN.md)** for the full playbook, weekly routine,
and copy-paste templates.
